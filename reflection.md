# Reflection

This was my first time using CODEX, while I have used Copilot in my job, I am very surprised how little direction this platform needed. I started the terminal in a folder with the data set and asked one question and was able to gather the answer to my question without any intervention. Usually AI needs clean data or multiple directions to get the results intended. I did not see CODEX struggling much at all, there was one section that it "failed" and it auto corrected itself without my intervention at all. I am interested to see how this platform will work in the group project since there is so much more raw data and multiple sources of data. I will be asking codex to cross reference the sata in the folders and am curious if it is able to do that with as little direction as it needed today.
